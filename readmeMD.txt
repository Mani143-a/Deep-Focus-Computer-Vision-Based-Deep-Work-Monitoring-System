# DeepFocus

DeepFocus is a real-time computer vision system for monitoring deep-work sessions.

## Features

- Face detection
- Eye Aspect Ratio (EAR)
- Eye closure detection
- Drowsiness detection
- Sleeping detection
- Away-from-desk detection
- Head-pose analysis
- Distraction detection
- Reading-context protection
- Machine-learning inference
- Rule + ML fusion
- Adaptive focus scoring
- Intelligent intervention
- Audio intervention
- Session analytics
- Historical session analysis
- Streamlit dashboard
- Runtime health monitoring
- Evaluation and benchmarking
